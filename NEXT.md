# Platform support: validated (2026-11-06)

Worktree `platform-support`, branch `codex/platform-support`, based on compiler 91b749e.
The main checkout is shared; do not edit it. The lead integrates the validated result.

## Implemented

- A separate checked-in AArch64 runtime IR, selected by the actual triple; cache keys
  include that triple. Linux AArch64 freestanding startup/system calls/memory routines.
  The ABI tests always generate an AArch64 ELF. The programs harness accepts
  FA_NATIVE_RUNNER for QEMU; user commands do not gain a runner option.
- `fa test --target=wasm`, a host import selecting each test body, fresh process/instance,
  native/wasm timeout handling and watch mode preserving target and asynchronous mode.
- `build.cLibrary` on wasm: raw module, header and importable Node/Bun factory;
  independent instance state, automatic initialization, raw API exports, temporary
  allocation helpers and idempotent dispose(). No fake static archive.
- Global resource ownership flags survive from library init to finalization. Imported
  resources nested in a foreign namespace resolve their destructor by exact self type
  through Interface::type_method. The helper was shared with the metadata engineer.
- `CString.toString()` on wasm/freestanding has a generated byte loop instead of libc strlen.
- Async proof fixtures synchronize writer/reader phases instead of assuming a short timer
  determines scheduling. This same fixture has already been copied into the lead.
