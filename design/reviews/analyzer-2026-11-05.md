# Analyzer review, 2026-11-05

Independent review of `packages/analyzer` (and `packages/interpreter`) at `compiler` 7a75f47. Every finding was reproduced with `target/release/fa check` (release build, `ulimit -v 8000000`); "runtime" means also run with `fa run` (Bun). Repros are in `design/reviews/repros/` (named in brackets). "Accepted" = no diagnostic.

Ranking: unsound acceptance > wrong rejection > crash > performance > missing test > diagnostics > cleanliness.

## Unsound acceptance

1. **Effects on another file's module-level value are dropped** [`cross-file-effects/`]. `touch()` (other file: `shared.push("y")`) inside `for item in shared` and after `use head = try shared[0]`: accepted, runtime OOM loop. Same code in one file gives EFF001, REF001, REF012. Cause: `check/effects.rs:1712` `self.module_values.get(&key)?` silently returns when this file never named the value. Fix: resolve `PathRoot::ModuleValue` through the module's imports/proxies; on a miss invalidate conservatively, never skip.
2. **A function writes another file's `mutable` without `mutates`** [`cross-file-write/`, `library/bump.fa`: `counter = none`]: no EFF003. Cause: `effects.rs:323-327` returns `Owner::Outside` ("not tracked as effects yet"). Fix: map proxy/alias symbols to `Owner::Module(key)`.
3. **A write inside a lambda keeps the facts outside** [`lambda-write-keeps-facts.fa`]: `mutable divisor = 1 · run(() => { divisor = 0 }) · 10 // divisor` is accepted and prints 0 (also: `x = none` in `start do` then `x + 1` → NaN; `a.clear()` in a lambda then `a[2]` → undefined). Cause: `effects.rs:415` skips `drop_place_facts` for a whole-place non-call write, also when replaying a closure's effects (`effects.rs:1272`, `tasks.rs:635`). Fix: always drop facts when replaying captured effects.
4. **A lambda trusts its creation-time facts though it breaks them itself** [`lambda-called-twice.fa`]: `twice(() => { console.log(10 // d) · d = 0 })` accepted; the 2nd call divides by 0 (narrowing variant prints NaN). A11 allows creation facts but nothing removes the places the lambda (or a sibling lambda argument) writes. Fix: at lambda entry drop the facts of every place written by the lambdas of the call, as at a loop head.
5. **Writes to parameters/module values inside a lambda never reach the enclosing signature** [`lambda-param-write-effect.fa`]: `bump = (p: Player) => run(() => { p.score += 1 })` has no EFF001; `bump(alice)` mutates a `let` (prints 1). Declaring `mutates p.score` gives a false EFF011. Fix: fold replayed captured effects into the enclosing `FnCx` (coverage + accumulation, `effects.rs:1186-1279`).
6. **Effects of a default value are charged to the caller** [`default-value-throws.fa`]: `function f = (x: Integer = try fail()) => x + 1 · f()` accepted, uncaught `E.Bad` at runtime. Spec: defining-functions.md:108 "A default value runs inside the function: its effects … are effects of the function". Cause: `check_params` (`functions.rs:441`) runs before the `FnCx` push (`functions.rs:542`). Fix: check defaults inside the function's `FnCx`.
7. **A `use` keeps its narrowed type after its place is replaced** [`use-keeps-narrowing.fa`]: `if box.value is not none { use v = box.value · box.value = none · v.length }` accepted, runtime TypeError. Cause: `references.rs:69` declares the alias with the narrowed type. Fix: declare with the place's declared type, keep the narrowing as a flow fact on the alias.
8. **Replacing a union does not invalidate references into the old member's payload** [`union-replace-payload-ref.fa`]: `use first = try shape.tags[0] · shape = Shape.Square {…} · first` accepted. Spec: reference-checking.md "Owning edges: the payload of a union … yes". Cause: `references.rs:592-597` returns false when the field isn't found on the union. Fix: treat an unknown field below a replaced union as invalidated (or record a `Payload` step).
9. **A captured reference is read through a named local function after invalidation** [`local-function-captured-ref.fa`]: `use first = people[0] · function show = () => first.name · people.push(…) · show()` accepted. Fix: at a call of a local function, check the state of each alias it captures.
10. **Callback given by name hides captured-reference overlap** [`callback-capture-overlap.fa`]: `people.deleteWhere(younger)` where `younger` captures `use ana = people.add(…)`: accepted; the lambda form gives REF013. Fix: include named functions' captures in `check_aliasing` (`effects.rs:1565`).
11. **Argument aliasing ignores the callee's module reads** [`module-value-alias.fa`]: `grow(config)` where `grow` holds `use first = config.names[0]` and pushes to `target.names`. Spec: reference-checking.md "Arguments that alias … any module-level value the callee reads". Fix: add the summary's `module_reads` to `check_aliasing`.
12. **Set elements and map keys mutated through a call / `keys()` loop** [`set-elements-mutated.fa`]: `for hero in heroes { boost(hero) }` (`mutates hero.power`) accepted, the set ends with two equal heroes; `key.push("b")` on map keys accepted. Direct `hero.power = 5` is CL031. Cause: `place_writable` (`effects.rs:296-314`) ignores `readonly_elements`. Fix: return `No` for read-only elements.
13. **Copy wrongly turned into a move (observable)** [`move-through-function-value.fa`, `move-mutable-use-branch.fa`]: `let call = show` (captures `numbers`) then `mutable other = numbers · other.push(4) · call()` prints 4 on Bun and native (native reads memory now owned by `other`). With `mutable use current = alice` + `reuse` in one branch, `mutable moved = alice` is moved. Cause: `moves.rs:61-84` follows captures only through `SymbolKind::Function` names, and `self.aliases` is not flow-sensitive. Fix: a function used as a value pins its captures; take an alias's places from `FlowState::refs`.
14. **A moved task is awaited again through a capturing local function** [`task-awaited-twice.fa`]. Fix: MEM002 treats a call of a local function as a use of its captures (same root as 9 and 13).
15. **Reference return types are not validated** [`reference-return-types.fa`]: `(): Person in local` (a body local) and returning `local[0]` for `: Person in people` are accepted (REF008/REF009 have no emitter). Fix: resolve the `in` root in signatures and check returned places.
16. **Error type in a return type accepted** [`error-in-return-type.fa`]: `function f = (): Integer | E => 1`. Spec: errors.md:120 "Errors are never part of the return type". E-ERR-7 has no emitter (case T-ERR-19 pending). Fix: emit E-ERR-7 when a written return/value union holds an `Errors` type.

## Wrong rejections

17. **`is in` on an array is AN001** [`is-in-array.fa`]: `role is in ["admin", "moderator"]` (logical.md:140, conditionals.md:109) → "not supported yet". Fix: implement membership + literal-array narrowing (T-CMP-11, T-NAR-7 pending).
18. **Fields of a just-built union member** [`union-member-fact.fa`]: `let s = Shape.Circle { r = 1 } · s.r` → TY021. Spec: unions.md:78 "known to hold a `MyUnion.Car`: its fields can be read". Fix: record the member fact when binding a typed member literal (`objects.rs:1252`).
19. **`when` over an optional named union never exhaustive** [`when-optional-named-union.fa`]: `Shape.Circle`, `Shape.Square`, `none` → E-WHEN-1. Cause: `patterns.rs:508-521` doesn't expand `NamedUnion` members inside an anonymous union. Fix: expand recursively.
20. **Ordering under a constraint** [`generic-ordered-constraint.fa`]: `<Item: Integer>` then `a > b` → E-CMP-2 (generics.md:141). Cause: `ops.rs:446` tests `ORDERED` on the `Param`. Fix: test every member of the constraint.
21. **String `+` at compile time** [`comptime-string-concat.fa`]: `@f()` with `"a" + "b"` → META005 "not numbers". Cause: `comptime/lower.rs:868` has no string case. Fix: lower to `Expr::Template` like `+=` (`lower.rs:919`).
22. **A non-stored callback of a user function can't throw** [`callback-throws.fa`] → E-TYPE-1 (defining-functions.md "Functions as parameters"); known (fp-4/fp-5 pending M2). EF018 has no emitter.

## Crash

23. **Standalone `fa check file.fa` overflows the 8 MiB main stack** [`stack-overflow-chain-1500.fa`: 1,500 functions `c_i => c_{i+1}(x) + 1`; an 800-function SCC too]: abort. Package mode survives (64 MiB workers, P8). Fix: run `Loaded::load` (`packages/cli/src/lib.rs:481`) inside `parallel::pool()` or a `STACK_SIZE` thread.

## Performance (1,000-file package: OK)

- Positive: `generate.ts --files 1000` (505k lines): 15-18 s wall, 22.9 s CPU, **163 MB peak RSS** (6 threads), 156 MB (1 thread). Diagnostics byte-identical for 1/2/3/6 threads and seeds 0/1/7/42. Host load was 10-19, so wall times are inflated.
24. **Union normalization is ~n³-n⁴** [`slow-literal-union-250.fa`]: a 250-member string-literal union + exhaustive `when`: 2.1 s; 500: 24.5 s; 1,000: >120 s. A 1,000-arm `when` on a `String`: 36 s. Cause: `TypeStore::union` (`types/union.rs:65-100`) runs all-pairs `assignable` for absorption plus `scratch.remove`; rebuilt per arm by `narrow_to_text_literal` (`ops.rs:895`) and per-arm `join_states`. Fix: only non-literal members can absorb; join arm states once, n-ary.
25. **Named-union/enum narrowing is per member**: 2,000-arm `when` 1.7-5.8 s, 140 MB of `assign_cache`. Fix: narrow by mask arithmetic, no `assignable` per member.
26. **`is_operand_or_receiver` scans the whole tree per conversion** (`numbers.rs:1822`): 8,000 `Integer(v32)` lines take 2 s (~n²). Fix: use a parent table (one exists in `locals.rs:51`).
27. **Second target re-analyzes everything**: `--target-share 0` with `targets = ["bun", "native"]`: "programs analyzed: 2", 16.5 s vs 7.6 s for one target. Fix: find the spurious `reads_target`/unstable interface hash (`streaming.rs:152`, `pipeline.rs:985-1019`); test that a second target skips all units when nothing reads `target`.
28. **P8 not implemented**: the binaries wrap glibc `System` in `CountingAllocator` (`packages/cli/src/native_main.rs:12`), not mimalloc. Fix: make the counter generic over mimalloc.
29. Minor whole-tree scans per item: `direct_side_declarer` (`relations.rs:562`), `pool_never_timed` (`concurrency.rs:409`). Fix: index declarations by name once per file.

## Missing or ineffective tests

30. **95 of 474 registered codes have no emitter** anywhere in `packages/*/src` (e.g. E-ERR-7, E-CMP-6, E-CMP-8, E-CMP-10, E-LOOP-2, E-LOOP-4, E-LOOP-14, E-WHEN-4, W-WHEN-1, W-WHEN-2, W-DO-1, W-ERR-4, MEM001, REF008, REF009, REF017, EF018, EFF010, CONC009). Some are documented rules: conditionals.md:439 (unreachable branch warning, [`when-unreachable-arm.fa`] accepted silently), the pure statement warning (T-DO-9, [`pure-statement.fa`]). Fix: a registry test listing codes without emitter, each either implemented or marked `reserved`.
31. **About 85 codes are expected by no case** (e.g. GN002, GN008, TF002-TF027, TY001, TY012, CONC009, CONC011, FFI012-FFI014, META004, MOD011/MOD012). Fix: one case per code, enforced by the registry test.
32. **142 pending cases (72 still "M1")** don't constrain the analyzer; **5 pass now and keep `pending`**: adv-6.8-05, adv-17.4-01, fp-1, fp-2, cl-4 (`FA_STRICT_PENDING=1` fails). Fix: drop their headers; run `FA_STRICT_PENDING=1` in CI.
33. **No case** for findings 1-14, 18-21: multi-file REF001/REF012/EFF003, lambda writes to captured locals/params/module values, effects of defaults, member fact after a literal, optional named union `when`, ordering under a constraint, compile-time string `+`, set elements through a call.

## Diagnostics

34. REF001 is emitted twice with the same span for one read [`ref-duplicate-report.fa`], and every later use of an invalidated reference is reported again [`ref-error-cascade.fa`]. Fix: dedupe by (node, code); mark the reference reported.
35. REF001's fix suggests repeating the initializer: "declare it again with `use ana = people.add(…)`", which adds a second element (`references.rs:497`). Fix: suggest `find(…)` or `let` for a call initializer.
36. A `mutable use` invalidated on one branch only gets REF001 "was invalidated" instead of REF002 "may have been". Fix: REF002 when only some designated places are reached.
37. E-OPT-1 quotes the operator, not the operand: "`x + 1` may be `none`: test it with `if x + 1 is not none`" (`narrowing.rs:576-598`). Fix: pass the operand node.
38. Follow-on diagnostics: E-TYPE-1 + W-ERR-1 + W-ERR-3 for one rejected argument; TY021 + false EFF011; E-TYPE-1 + STR005 on one span. Fix: suppress warnings on an expression already rejected.
39. Wrong code for documented mistakes: `break outer` → E-DECL-1 + E-LOOP-7 (should be E-LOOP-14); `for [a, b] in pairs` → E-ERR-3 (E-LOOP-2); `x is in 4` → "`is in` on a collection is not supported" (E-CMP-6); a member of a value narrowed to `none` → AN001 (E-OPT-1). [`is-in-array.fa`]
40. CONC002 suggests the code already written when an inner `for index` shadows the loop index; EFF001 suggests `mutates p` for an effect on `p.score`; REF001 describes `text += "!"` as `text = …`. Fix: name the shadowing; suggest the precise path; print the operator used.
41. Past 128 nesting levels, AN002 is followed by a second AN002 "Expected '{'" at the end of the skipped region. Fix: skip to the matching close token.
42. Undocumented compile-time limit "nests more than 3178 calls" (metaprogramming.md lists only steps, 256 MB, 256 type-function levels). Fix: document it (or derive it from the stack size).
43. No W-ERR-3 for an unused `throws` on a single-expression body (block bodies get it).

## Cleanliness

44. **The "one walk" is ~9 passes per file**: after the walk, `check/mod.rs:597-609` runs `finish_modules`, `finish_tasks` (fixpoint), `finish_c_library`, `finish_relations`, `finish_moves`, `finish_reactivity` (a full second visitor, `reactivity.rs:911`), plus `record_non_escaping` (2 scans + parent table), `check_deferred_key_loops`, `check_parallel_views`; `scan.rs:146` re-traverses each tree (P4 wanted it fused into the parse). Fix: fuse `record_non_escaping` and `finish_moves` into the walk; build the parent table once.
45. **Side tables sprawl**: `Analysis` has 47 public fields, 33 of them `FxHashMap<NodeId, _>` (`analysis.rs:580-793`; design §2.6 lists ~9); `Walker` has 68 fields (`check/mod.rs:311`). Fix: one map per feature group (comptime, reactivity, foreign, async, relations) and per-feature state structs, as `key_sets`/`foreign`/`tasks` already do.
46. **Long functions**: 18 over 200 lines, 60 over 100 — `publish_interface` (`interface.rs:28`, 298), `finish_relations` (294), `check_runtime_call` (`calls.rs:94`, 276), `check_function` (`functions.rs:406`, 271), `apply_call_effects` (`effects.rs:1295`, 265), `relation_field` (263), `check` (`mod.rs:626`, 235).
47. **Duplicated knowledge**: the lists of mutating method names are copied in `comptime/lower.rs:1748`, `builtins/array.rs:398,474`, `builtins/effects.rs:100`, `reactivity.rs:1366`, `proofs.rs:271` (the comptime copy lacks growing/`Map` methods); NamedUnion/Enum member iteration `(0..count).filter(mask_has)` is hand-written 13 times in 8 files; exhaustiveness has two checkers (`patterns.rs:455`, `narrowing.rs:698`). Fix: derive from `builtins::get(id)` effects; add `TypeStore::mask_members`; one exhaustiveness checker.
48. Dead code: `functions.rs:455` `let effects = false;` makes `self.quiet += u32::from(effects)` / `-=` (`:554`, `:560`) no-ops. Test helpers duplicated (`strings.rs:225,235` vs `test_support.rs:30,45`; the same node lookup in `lower/{calls,copies,index,when}.rs`). No `#[allow(dead_code)]` in the crate.

## Checked and sound

- Parallel bodies: writes via closures, local functions, `mutable use`, methods, and other functions are caught (CONC002/012/013).
- Narrowing is dropped after reassignment, `mutates` calls, `use` aliases, in loops, and after `await` of module values.
- Iteration invalidation, `use` of `use`, slices, generic and recursive effects, and `catch`/`do` paths are handled.
- Compile-time limits (100 M steps, 256 MB, META003) and purity hold.
- Enum, Boolean, literal union and integer range exhaustiveness all work.
