# Review of the two backends (2026-11-05)

Independent review of `packages/codegen-js` and `packages/codegen-llvm` at `compiler` 7a75f47. Every
repro is in `design/reviews/repros/`. "bun" is `fa run`; "native"/"wasm" is `cargo run -p
fa-codegen-llvm --example build -- f.fa --target=… --leak-check --run`; "release" means checks off
(`fa build` on JS, `--overflow-checks=false` natively).

The three targets agree on almost everything else I tried. That covers integer edges (`Int64.minValue // -1`, shifts
by the width or more, bit operations above 2^32) and float printing (1e21, 1e-7, -0, NaN, 5e-324,
Float32). It covers grapheme strings (ZWJ families, flags, combining marks, CRLF, negative slices, code-point
order of `<`/`sort`) and value semantics of nested collections, unions and tuples. It also covers `-0`/NaN keys, JSON,
relations, pools, escaping closures, `Task.all/any`, channels and errors through callbacks. Native
hello is 4.7 KB (C with glibc: 14.5 KB). The defects are in the optimization proofs, in JavaScript
naming, in a few task semantics, and in release-mode integers.

## 1. Wrong results, crashes, leaks

1. **Critical: the field index proof misses an object of a wider type** (`proofs.rs:541`: `Claim::Field`
   counts only literals of exactly the owner type). `proof-field-wider-type.fa`: bun `99`; native
   segfaults (printed as `stop: stack overflow`, see 15); wasm `memory access out of bounds`.
   *Fix:* fail the claim when another type flows into the owner type.
2. **Critical: the same proof misses a literal in a generic body** (`proofs.rs:541`: its type is
   `Holder(Value)`, not `Holder(UInt32)`). `proof-field-generic-literal.fa`: bun `99`; native `0`
   (it read past the end); wasm out of bounds. *Fix:* match the generic definition, or fail.
3. **Critical: `Claim::Items` ignores arrays built by built-ins** (`proofs.rs:617` skips calls on another
   receiver type, e.g. `map`). `proof-items-builtin-result.fa`: bun `99`; native segfault; wasm out
   of bounds. *Fix:* any node of the claimed type that isn't a literal or a vetted call fails the claim.
4. **Critical: `Claim::MapValues` ignores `Map.from`** (`proofs.rs:667`). `proof-map-values-from.fa`: bun
   `99`; native segfault; wasm out of bounds. *Fix:* same rule as 3 (`from`, `getOrInsert`, `map`).
5. **Critical: a dense map moves under a live reference** (`facts.rs:723`: `short_reference` counts
   `m[k] = …` as a change only when `m` is a name or a field). `dense-map-indexed-insert.fa`: bun `3 1501`,
   native/wasm `0 1501`. The writes land in freed memory, and the leak check doesn't see it. *Fix:* any indexed
   assignment into a map changes it; better, read the statement's analyzed effects.
6. **High: destination passing ignores a callee that reads the destination as a module-level value**
   (`lower/destination.rs:57-75`, `:205`: only captures and arguments are checked). `destination-module-read.fa`:
   bun `ab[xab]`, native/wasm `ab[xab[x]`. *Fix:* reject callees that read the destination's root symbol.
7. **High: never-negative assumes a 64-bit wrap in release** (`proofs.rs:308`, `:743-756`: `+= 1` accepted
   on an `Int8`). `never-negative-narrow-wrap.fa`, checks off: native `-1 99 99`, expected `-1 30 30`.
   Items 1–2 also fool never-negative: `never-negative-wider-type.fa` gives bun `30 20 30 10`, native and wasm `99 20 99 10`.
   *Fix:* bound the steps by the storage width when checks are off.
8. **High (native/wasm leak): `Task.settled` leaks each heap result** (`lower/tasks.rs:2840`, `store_settled`:
   the moved-out raw result is wrapped by `Val::new`, copied by `take`, never freed).
   `task-settled-leak.fa`: bun `2`; native/wasm `2` + `leak: 2 blocks`, exit 102. *Fix:* treat it as fresh (no copy).
9. **High (all targets): `await f()` where `f` only starts tasks makes them eager and blocking** (one
   synchronous instance that raises the blocking depth). `await-makes-starts-eager.fa` prints `task starts, task
   ends, run returns, after run` everywhere. `concurrency.md` says "a started task does not run right
   away", so the expected order is `run returns, after run, task starts, task ends`. *Fix:* reaching `f` through `await` must not count as a blocking call.
10. **High (all targets): a detached task copies a module-level `mutable`** instead of reading it
    (`defining-functions.md`: module-level values are not captured). `detached-task-copies-module-value.fa`:
    `shared 1` everywhere, expected `shared 2`. wasm also printed `end 2` before `shared 1` (10 ms before 5 ms).
    *Fix:* leave the top-level bindings out of what a `start` copies.
11. **High (JS): a field named `__proto__` sets the prototype**. Property names are never quoted
    (`names.rs` renames only bindings). `js-proto-field.fa`: bun drops the field, and `w.constructor + … +
    w.__proto__` prints `6[object Object]`; native `10`. *Fix:* emit `["__proto__"]: v`, or rename the property.
12. **High (JS): a module-level value named like a runtime global crashes** (`names.rs:20` `RESERVED` lacks
    `TextEncoder`, `Uint8Array`, `Promise`, `Atomics`, `SharedArrayBuffer`, `DataView`, `setTimeout`,
    `performance`, `Bun`…). `js-global-names.fa`: bun `TypeError: 2 is not a constructor (evaluating 'new TextEncoder')`;
    native `2 3 3 4 300 éé`. *Fix:* derive the list from the globals the runtime files use, with a test.
13. **Medium (JS): tasks held in an array, object or optional aren't cancelled at scope end**
    (`generate/tasks.rs:1174` `holds_task`: only a declaration of type `Task`). `js-held-task-not-cancelled.fa`:
    bun prints `finished 10`, `finished 30`, `end`; native/wasm only `end`. *Fix:* a JS drop walk driven by "contains a task".
14. **Medium (JS): `==` of a value with itself is `true` despite NaN** (`runtime/equality.js:149`: the
    `a === b ||` shortcut). `js-nan-identity-equality.fa`: bun `true false false true false`, native
    `false false false false false` (`values == copy`, `points == points`). *Fix:* no identity shortcut for float-holding types.
15. **Medium (native): every SIGSEGV is reported as `stop: stack overflow`, exit 101** (`fa_runtime.c:4534`
    `on_fault`). That is how 1, 3 and 4 showed up as clean stops. *Fix:* `SA_SIGINFO` and `si_addr` against the guard page, else re-raise.
16. **Medium (JS): Fa errors are recognized by `value.constructor?.faName`** (`faIsError`, `faFormat`): a field
    `constructor` holding an object with `faName` prints `[object Object]` (`js-constructor-field.fa`;
    native prints the object). *Fix:* `instanceof FaError` or a private symbol.
17. **Medium (JS, release): `Int64`/`UInt64` don't wrap.** `js-release-int64-no-wrap.fa` built by
    `fa build`: bun `18446744073709551616 18446744073709551616 false true -1`, native `0 0 true true 0`. An
    `Int64` ends up holding 2^64, and `Int64.minValue // -1` gives `9223372036854775808`. `numbers.md:262` promises a
    wrap natively and precision loss only for `Integer`; `Int32` does wrap on JS. *Fix:* `BigInt.asIntN` when unchecked (see 31).
18. **Medium (native): case mapping covers ASCII, Latin-1, Greek and Cyrillic only, with no final sigma**
    (`fa_runtime.c:2167`). `native-case-mapping.fa`: bun `ŁÓDŹ ČEŠTINA σας Ǆ ａｂ`, native
    `łÓDź čEšTINA σασ ǅ ＡＢ`. This is undocumented. *Fix:* generated Unicode tables, or document the gap.
19. **Medium (perf, all targets): `list = List { head = i, tail = list }` deep-copies the old list** (JS
    `e={head:t,tail:w(e)}`): `list-prepend-quadratic.fa` with 20 000 nodes takes 24 s native and 19 s on bun.
    *Fix:* the read of a place that the same assignment overwrites is a move (a shared analyzer fact).
20. **Low (JS): a worker call cancelled right after `start` still runs** (`runtime/workers.js:291-318`
    posts the call, then the cancel). `repros/worker-cancel/`: bun shows `…,cancelled0`, while native skips the call.
    Also, `fa run f.fa --target=native` passes the flag to the program and silently runs on Bun.
21. **Low (JS): JSON keeps a lone surrogate** (`\ud800`), which is not valid UTF-8. `js-json-lone-surrogate.fa`: bun
    `false ["\ud800"] 3`, native `true ["�"] 3`. *Fix:* `toWellFormed()` on parsed strings.
22. **Low (spec):** `Integer(2.9)` compiles and truncates on every target, though `numbers.md:447` requires
    choosing a rounding (`Integer.round`…). *Fix:* reject it in the analyzer.

The documentation allows these, but they show: map iteration after a delete (bun: insertion order; native: the
hole is reused), and `sort` with a NaN comparator (bun `[3.5, NaN, -1, 0, 0, 1]`, native `[-1, 0, 0, 1, 3.5, NaN]`). Native-only gaps: `BigInt`, `Float.parse`, `Task<String>?`, `Array<String?>.get`.

## 2. Unsound proofs: what held

Items 1–7 are the unsound ones. These held: shrinking the indexed array through a callee, a closure, a `use`, a generic or a whole
assignment (rejected by `array_family`); parameter claims through function values, partial
application and defaults; `hoisting.rs` with aliases; split views leaving their scope; in-place string edits
with negative or reversed bounds; reserved appends; `a = [a[1], a[0]]`; `s = s[1..] + s`; JS `natural_division`.

## 3. Missing tests

23. **The LLVM harness can't fail on a program that stops compiling.** `tests/programs.rs:277-281` turns
    `Unsupported` and even `Diagnostics` of every non-required program (all of `cli/tests/programs`
    and the analyzer cases) into "skipped", with no ratchet. Native today: `652 passed, 31 skipped` (24
    are unsupported constructs: `big-integers`, `references`, `tuples-ranges-patterns`…). *Fix:* a checked-in list of expected skips.
24. **A test locks in 17:** `codegen-js/src/lib.rs:943-946` asserts `return x * 3n;` ("`Int64` don't [wrap]").
25. `field-index-proofs.fa` covers only shrinking, an out-of-range literal and function values. Nothing covers wider types, generic
    literals, built-in results or `Map.from` (1–4). `non-negative-fields.fa` never runs with checks off (7).
26. `dense-maps.fa` has no change through an indexed place (5), and `destination-passing.fa` has no callee reading a
    module-level destination (6).
27. No test for `Task.settled` with heap results under the leak check (8), a function that only starts tasks
    reached by `await` (9), a detached task reading a module value (10), or tasks inside collections at scope end on JS (13).
28. No JS test of special property names (`__proto__`, `constructor`) or of module names equal to runtime globals (11, 12, 16);
    no test of NaN in `==` of a value with itself (14).
29. No test of `toUpperCase`/`toLowerCase` beyond ASCII on any target (18).
30. Single-file programs never take the per-unit path (`programs.rs:293`: split only with `application/main.fa`),
    though `facts.rs` (5) feeds both paths.

## 4. Output size

31. **JS printing is not type-directed:** `console.log([1, 2, 3])` is 2.6 KB minified, because `faFormat` pulls in the map,
    set, pool, range, union and object formatters (the `golden/types.js` header lists `faFormatMap`/`Set`/`Range` for a `Point`).
    *Fix:* choose the formatter from the static type.
32. **JS enum equality goes through `faEquals`:** `color == Color.blue` → `A(e,2)`, a 6 KB program
    (`js-enum-equality-size.fa`). `Repr` (`generate/mod.rs:61`) has no enum case, so `equality`
    (`expressions.rs:342`) misses `===`. *Fix:* make enumerations `Repr::Number`.
33. **JS hello world is 919 B** (web target too) for `console.log("Hello, world!")`: `faRun`, `faReport`,
    stack-overflow detection and `process.exit`, for a program that can't stop or throw. *Fix:* call `main()` directly then.
34. **JS `static` ranges aren't folded:** `static-ranges.fa` (446 B) builds to 4.9 KB, with `FaRange` objects, the iterator
    protocol plus an overflow helper for `for index in span`, and the generic formatter for `1..5`.
35. **Narrowing doesn't feed intervals:** `n - 1` in the `else` of `n < 2` stays checked (`golden/functions.js`),
    and so do `count + 1`, `i * i` and `multiple + i` in `golden/hot-loops.js`. *Fix:* interval facts from comparisons (shared).
36. **wasm loader: 4.2 KB, unminified, for a 346 B `hello.wasm`.** It ships comments, the async event loop, the `env.mjs`
    plumbing and the tests' `checkMemory`. *Fix:* keep only the `@import` parts that are used, and minify.
37. Native: printing a constant array formats it into a heap string (+6 KB: `printarr` 10.7 KB vs hello 4.7 KB).
38. JS: `const copy = copy$Point(point)` is emitted although `point` is never written again (`golden/types.js`).

## 5. Cleanliness

39. **Index proofs are LLVM-only.** `codegen-llvm/src/proofs.rs` (1213 lines) is semantic, but JS uses only
    `fa_analyzer::lower::index`, so it keeps the checks native drops (`field-index-proofs.fa` → `i(t,n).next`).
    Moving the prover to the analyzer means 1–4 and 7 get fixed once, and JS gets the eliminations.
40. **There are two copy policies.** JS asks `fa_analyzer::lower::copies`, while native decides in `lower/ownership.rs` (2070
    lines). Items 19 and 38 show both are conservative in different places.
41. **"Contains a task" is decided twice:** the native drop glue knows it; JS `holds_task` rescans the
    tree per declaration (O(nodes × calls)) and misses nested tasks (13).
42. **`facts.rs::short_reference` reads syntax shapes** to decide whether a map changes, which is the root of 5.
43. Some functions are very long: `lower/arrays.rs:1088` `array_method_more` (570 lines, the overflow of `array_method`,
    called from 5 files), `lower/tables.rs:1472` `table_method` (422), `units.rs:550` `entry_object`
    (370), `lower/ownership.rs:655` `build_copy_body` (292); `lower/tasks.rs` is 4076 lines.
44. "Unsupported" messages dump internal types: `converting a value from Enum(NominalId(2147483659)) to
    Int(IntRepr { bits: 64, … })`. *Fix:* name the Fa types.
